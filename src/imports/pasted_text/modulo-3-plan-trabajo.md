============================================================
REGLA FUNDAMENTAL DEL MÓDULO
============================================================

El sistema NO es Microsoft Word.

NO crear:
- páginas completamente libres;
- herramientas avanzadas de maquetación;
- cambio de tipografías;
- colores de texto;
- tamaños arbitrarios;
- columnas libres;
- cajas flotantes;
- editor visual de páginas.

El Plan de Trabajo utiliza una plantilla institucional estructurada.

El docente únicamente completa las secciones editables.

El sistema genera automáticamente:
- encabezados;
- numeración;
- matriz;
- firmas;
- historial;
- formato institucional;
- PDF final.
